# Quora Duplicate Question Detection

A machine learning project for detecting whether two Quora questions are duplicates.

## Approach

- Exploratory Data Analysis (EDA)
- Text preprocessing
- Feature engineering
- Bag of Words (BOW)
- Fuzzy text similarity features
- t-SNE visualization
- Random Forest classification

## Dataset

This project uses the Quora Question Pairs dataset (`train.csv`).

## Tools

Python, Pandas, NumPy, Scikit-learn, NLTK, FuzzyWuzzy, Seaborn, Matplotlib
